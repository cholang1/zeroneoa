# Zerone OA · 团队工作台

Zerone OA 用于安排团队每周的工作，记录每天的进展和工时，并跟进工作中遇到的问题。成员可以从周计划一路回看到具体日报，团队也可以按成员或任务汇总工时。前端使用
React、TypeScript 和 Vite，后端使用 Node.js 和 MongoDB。

## 主要功能

| 入口     | 功能                                                     |
|--------|--------------------------------------------------------|
| 总览     | 查看团队日历、任务树和备忘，了解本周工时、未完成计划和待解决问题。                      |
| 工作内容   | 按周查看个人或团队的工作，关联任务、填写周计划和日报、登记工时，在当天的评论区讨论。             |
| 问题     | 日报里的「问题／注意」自动汇集到这里，无需重复录入。可以补充解决方案，标记和筛选处理状态。          |
| 统计     | 按成员或任务汇总已填报的工时。                                        |
| 数据     | 查看数据规则、一级任务和近期操作。右上角菜单提供导入和导出，导出可选时间范围及 JSON 或 CSV 格式。 |
| 成员管理   | 管理员从右上角菜单新增成员、开通或停用账号、重置密码。                            |
| ZeroAI | 按账号保存私人聊天。获得授权后，可用自然语言查询周计划、日报、工时和未解决问题，查看回答来源并继续追问。   |

## 首次运行

安装 **Node.js 22.12 或更高版本**（含 npm）和 **MongoDB**。日常填报和统计不需要 AI 密钥。

### 1. 安装项目依赖

从仓库根目录执行，后续步骤都在 `zerone-oa-web/` 下完成：

```sh
cd zerone-oa-web
npm ci
```

### 2. 连接 MongoDB

启动本机 MongoDB 服务。项目默认连接 `127.0.0.1:27018`，数据库名为 `zerone_oa_db`，集合和索引会自动创建。如果 MongoDB
使用常见的 `27017` 端口，在 `apps/api/.env` 中加入：

```dotenv
MONGODB_URI=mongodb://127.0.0.1:27017/zerone_oa_db?retryWrites=false
```

### 3. 设置首次登录凭证

运行下面的命令生成随机凭证：

```sh
node -p "require('node:crypto').randomBytes(32).toString('hex')"
```

在 `apps/api/.env` 中新增一行 `OA_SETUP_KEY=刚生成的随机值`，将等号右侧替换为命令的输出。文件不存在就新建。这个凭证只用于创建首个管理员，不是登录密码，不要提交到
Git。

### 4. 启动并登录

```sh
npm run dev
```

这条命令同时启动网页和 API。打开 <http://127.0.0.1:5178>，选择「首次设置」，填入初始化凭证、姓名、登录名和密码，创建管理员账号。

创建成功后，从 `apps/api/.env` 删除 `OA_SETUP_KEY` 这一行，按 `Ctrl+C` 停止服务，再运行 `npm run dev`。以后保持 MongoDB
运行，用这条命令启动项目，再用自己的账号登录即可。

## ZeroAI 配置（可选）

在 `apps/api/config/ai.yaml` 的 `ai.profiles` 中配置模型地址、模型名和密钥环境变量名，用 `ai.activeProfile` 选择模型。实际密钥放在
`apps/api/.env`，修改后重启服务。

聊天不会自动获得 OA 数据权限。要启用只读查询，在 `ai.readTools` 中核对模型指纹和授权范围。普通成员只能查公共目录和本人的记录；查询他人记录需要管理员身份和团队查询授权。日报正文（
`allowDetail`）与问题及解决方案（`allowIssues`）分别授权，两者都不包含评论。

## 常用命令

以下命令在 `zerone-oa-web/` 下执行：

| 命令                  | 用途                                   |
|---------------------|--------------------------------------|
| `npm run dev`       | 同时启动网页（`5178`）和 API（`4318`）。         |
| `npm run typecheck` | 检查前端 TypeScript 类型。                  |
| `npm test`          | 运行前后端测试，MongoDB 用例默认连接本机 `27018` 端口。 |
| `npm run test:e2e`  | 构建网页并运行浏览器测试，默认使用 Edge。              |
| `npm run build`     | 构建网页，输出到 `apps/web/dist/`。           |
| `npm run api`       | 单独启动后端 API。                          |

部署时先构建网页，在后端设置 `NODE_ENV=production` 和 `OA_PUBLIC_ORIGIN`（网页的完整 HTTPS 源），再启动
API。通过反向代理在同一域名下提供网页和 `/api`；使用 ZeroAI 时，消息接口需允许流式响应。
